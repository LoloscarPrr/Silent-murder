# El Cuervo — Fase 9, primer prototipo real de animaciones
**Dos acciones 3D verificables:** Cuervo_Walk_InPlace y Cuervo_Aim_Raise.
Cuerpo, ojos, abrigo y botas reales desde la base CC0 MakeHuman / MPFB.
Un solo esqueleto de 53 huesos y archivos originales BLEND + GLB.
Caminata **en sitio**, sin desplazamiento global duplicado con Godot.
Ocho renderizados JPEG reales con poses clave, no conceptos de IA.
Esta versión es PARA REVISIÓN ARTÍSTICA, no para integrar directamente
al gameplay: faltan pie fijado/IK, arma y puntería real, mezcla de
animaciones, dinámica de tela, y FPS reales en Android.
Ningún archivo de main ni del personaje jugable se ha reemplazado.
