# Silent Murder — Dirección de arte aprobada

## Concepto

Assassin noir urbano + operador táctico discreto. Protagonista provisional «El Cuervo»: silueta estilizada, traje grafito, guantes negros, protección ligera integrada. Dos futuros atuendos: urbano (traje y equipo oculto) e infiltración (chaqueta táctica).

## Paleta

Grafito, pizarra, acero azulado y luces ámbar. Sin neón de ciencia ficción ni interfaz futurista.

## Alpha 0.2

El modelo actual es **articulado procedural y geométrico**, no el modelo definitivo. Se reemplazará por un personaje 3D humanoide con rig y animaciones de calidad cuando se apruebe el sistema de movimiento.

## Escenario

Depósito industrial nocturno con lectura clara de pasillos, cajas y coberturas. El mapa actual es un blockout.

## Reglas de diseño

Optimizar para Redmi 12 5G, evitar assets sin licencia y mantener identidad propia sin usar materiales ni código del juego Contract Killer 2.
