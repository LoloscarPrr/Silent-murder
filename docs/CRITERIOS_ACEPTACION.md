# Silent Murder — Criterios de aceptación 0.1

1. GitHub Actions produce un APK Android arm64 instalable.
2. Arranca en horizontal y muestra el escenario de depósito 3D.
3. Joystick izquierdo mueve al personaje sin que el control de cámara deje de responder.
4. Arrastrar a la derecha mueve la cámara.
5. Botones CORRER, AGACHAR y APUNTAR responden.
6. No cierres inesperados durante cinco minutos de desplazamiento.
7. Rendimiento objetivo inicial 30 FPS en Redmi 12 5G (pendiente de medir).

**No son criterios de esta fase:** guardias, armas, disparos, misiones, menú final ni animaciones profesionales.
Antes de distribuir una actualización permanente, configurar una clave de firma estable.
